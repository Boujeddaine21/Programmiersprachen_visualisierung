# Programmiersprachen-Visualisierung

Eine interaktive Webanwendung zur Visualisierung der historischen Zusammenhänge von Programmiersprachen auf Grundlage von Wikidata.

## Beschreibung

Die Anwendung stellt Programmiersprachen als interaktiven Graphen mit chronologischer Zeitachse dar. Beziehungen zwischen Sprachen werden als gerichtete Kanten visualisiert. Zusätzlich werden Beliebtheitsdaten aus dem TIOBE Index und der GitHub API als Balkendiagramme dargestellt.

## Technologien

- TypeScript
- D3.js
- Vite

## Voraussetzungen

- Node.js (Version 18 oder höher)
- npm

## Installation und Ausführung

1. Repository klonen:
\```bash
git clone https://github.com/Boujeddaine21/Programmiersprachen_visualisierung.git
\```

2. In den Projektordner wechseln:
\```bash
cd Programmiersprachen_visualisierung
\```

3. Abhängigkeiten installieren:
\```bash
npm install
\```

4. Entwicklungsserver starten:
\```bash
npm run dev
\```

5. Browser öffnen und folgende URL aufrufen:
\```
http://localhost:5173
\```
